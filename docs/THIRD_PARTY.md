# 第三方组件

| 组件 | 用途 | 版本 | 上游 |
| --- | --- | --- | --- |
| Python | 游戏运行时 | 3.14 | https://www.python.org/ |
| pygame-ce | SDL 原生窗口、绘制、输入与音频 | 2.5.8 | https://github.com/pygame-community/pygame-ce |
| PyInstaller | Windows 单文件程序打包 | 6.22.3 | https://github.com/pyinstaller/pyinstaller |

pygame-ce 及其分发的 SDL 组件使用上游声明的 LGPL 等许可证；PyInstaller 使用 GPL 及允许分发打包程序的例外条款；Python 使用 PSF 许可证。各组件及传递依赖的精确条款以上游包内附带文本为准。本说明不替换组件许可证。

游戏背景、图标和音效由代码绘制或合成。中文字体由 Windows 系统读取，仓库不包含字体二进制文件。以上第三方组件的许可不决定本项目源码的许可。
