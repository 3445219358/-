# 太虚问道 · Windows 原生版 0.2

双击 Windows 构建包中的 **TaixuAscension.exe** 开始游戏。无需安装 Python、无需浏览器、无需联网。程序使用 pygame-ce / SDL 原生窗口，内嵌运行环境与卡牌数据。

## 操作

| 操作 | 方法 |
| --- | --- |
| 开始 | 山门选择五个道统之一，点击「开始修行」 |
| 前进 | 点击左侧金色节点，完成后才能选下一步 |
| 出牌 | 点击手牌，或按 1–5 对应当前页的牌 |
| 手牌翻页 | 左右方向键，或点击箭头；手牌上限 10 张 |
| 结束回合 | 空格或「结束回合」按钮 |
| 卡组 / 图鉴 | 点击卡牌查看原始和升级效果对照 |
| 暂停 | Esc；暂停菜单可保存退出或回山门 |
| 全屏 | F11；默认 1280 × 800，可拖动窗口边缘调整 |
| 静音 | M 或暂停菜单 |

每次行动自动存档。再次启动点击「继续修行」。开始新局会弹出覆盖确认。失败结束当前局，已发现卡牌与局数记录保留。

## 当前可玩内容

- 五个流派：剑修、丹修、符修、体修、魔道，各有 12 张初始卡组。
- 三重地图，每重 12 个路径步骤；斗法、精英、奇遇、商店、静室、遗宝、首领。
- 60 张卡牌：基础 10、进阶 25、稀有 15、传说 5、天劫 5；每张有一次升级。
- 15 种普通敌人、可随机生成的精英变体、3 位具有半血第二阶段的首领。
- 24 件遗物、12 个奇遇、卡牌购买 / 移除、回复 / 升级二选一。
- 练气 → 筑基 → 金丹 → 元婴 → 化神；新境界最大气血 +8。金丹起奖励池开放传说牌。
- 本地自动存档、随机状态复现、卡牌图鉴、程序绘制的山景与流派标记、离线合成音效。

## 规则要点

每回合抽 5 张，灵力默认恢复 3；通过效果获得灵力最多到 6。回合结束弃掉全部手牌。

格挡保护本次敌方行动，下个玩家回合开始清零。意境每层给每次攻击增加 1 点伤害，战斗结束清空；剑修卡面将其称为剑意。护体每层减少 1 点攻击伤害。虚弱降低 40% 攻击伤害，易伤增加 20% 攻击伤害。

回合结束，中毒每层造成 2 点、灼烧每层造成 3 点气血伤害，随后减 1 层。这两类伤害与自损绕过格挡。自损致死立即败北，不能用后续伤害换取胜利。

消耗只移出本场战斗，下场仍在卡组。持续功法同名不叠加，升级版覆盖基础版。每回合最多 40 次出牌，阻止零费抽牌循环锁住游戏。敌人在第 16 回合起，每回合递增 2 点攻击伤害。

普通 / 精英 / 首领战斗基础灵石奖励为 18 / 32 / 45。三选一奖励可跳过，额外获得 12 灵石。商店基础 / 进阶 / 稀有 / 传说牌分别为 25 / 38 / 75 / 115 灵石，遗物 85，单店移除一次 50。卡组最低保留 5 张。

静室调息回复最大气血的 25%，向上取整。破境和层间提供额外回复。第一重第 6 步筑基，第一重首领后金丹，第二重首领后元婴，第三重首领后化神。

## 存档和故障记录

存档目录：`%LOCALAPPDATA%\TaixuAscension`。

- `run.json`：当前局与随机数状态。
- `profile.json`：局数、胜局与发现过的卡牌。
- `error.log`：发生未捕获错误时的日志。

Windows 10 / 11，64 位。中文文字使用系统自带微软雅黑与宋体。首次启动需要展开内嵌运行环境，耗时取决于磁盘速度。

## 开发状态

这是可以完成整局的原生可玩原型。当前版本没有商业美术资源、配乐、多敌人战斗、进阶难度、卡牌附魔、强化分支、成就、云存档、控制器适配和联网功能。单局 30–50 分钟是后续真人节奏测试目标，尚未验收。
